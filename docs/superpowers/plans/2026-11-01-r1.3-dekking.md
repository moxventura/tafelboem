# R1.3 "Dekking" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The kids' build counts in the fight: a bomb that lands more than 2 blocks from its kid
(they ran, or the build stopped it) lies still until someone walks into it, a yeet after a right
answer bends into a trap the kids built for one more hit, and on Peaceful and Easy nothing in an
arena takes a kid below half a heart.

**Architecture:** The rules are pure Java in `core/` with JUnit tests: the dodge and touch rule
(`Dodging`), the trap kinds and their reactions (`TrapKind`), the trap pick (`TrapPick`) and the
safety floor (`SafetyFloor`); the logs get their counts in `FightTally`, `FightRecord` and
`YeetReport`. On the Minecraft side `BossFight` keeps a fight's lying bombs, picks them up when a
kid touches one, poofs them at the end and lands Graaf Fout in traps; `Yeet` gets the pull (a short
scripted hop at the end of any flight); `TafelBoemWorld` gets the safety floor (through Fabric's
`ALLOW_DAMAGE`) and the `died` ending. Each feature has its switch in `TafelBoemConfig`, default on.

**Tech Stack:** Java 25, Fabric Loader 0.19.5, Fabric API 0.161.0+26.2 (incl.
`ServerLivingEntityEvents.ALLOW_DAMAGE`, `PlayerBlockBreakEvents.BEFORE`), Minecraft 26.2
(unobfuscated), JUnit 6, Fabric GameTests and client GameTests.

**Spec:** `docs/superpowers/specs/2026-10-07-tafelboem-design.md`, section *R1.3 "Dekking" (detailed
scope)*. Read it first; this plan argues from it. Read `AGENTS.md` too: its rules and GameTest
pitfalls bind every task.

## Spec notes (rulings where the spec leaves a choice open)

1. **"Where he would land"** is where he is when, on the last part of his flight, he comes down to
   3 blocks above the ground (or touches down, whichever is first): no physics prediction. The pull
   then takes over: a short hop (6–14 ticks, about 3 ticks a block) that arcs over whatever stands in
   between and puts him on top of a solid trap (cactus, magma, slime, a lying bomb) or in a soft one
   (cobweb, berry bush). "The last part" is per flight: the classic and tumble once airborne, the
   bounce only its last bounce, the boomerang only its drop in front of the kid, the helicopter only
   its fall, the wall splat its slide down the wall or its fall.
2. **Trap reactions.** Three new landings: `PRICKLED` (cactus, berry bush; he hops round and says
   *"Au au au!"*), `WEBBED` (cobweb; stuck and wriggling for 2 s) and `BOING` (slime; one more
   bounce). Magma plays the existing `FRANTIC_RUN`, a lying bomb the existing `SOOT` after its boom.
   Every trap block goes at the moment he is caught ("after it caught him, the trap block poofs"), so
   the cobweb is shown by particles while he wriggles. A trap landing replaces the picked landing
   and is not logged as a signature.
3. **Touching a lying bomb** also covers hitting it (it would otherwise break and drop a bomb item)
   and right-clicking it (it would otherwise start a free-play question with a free-play boom in the
   arena). Neither breaks it; both start its question when one can start.
4. **When a pick-up can start.** Only while Graaf Fout is not mid-kick or mid-reaction (phases
   cooldown, bomb in flight, someone answering). A kid standing on a lying bomb during a yeet gets
   its question the moment his reaction is over. Two questions at once (a sibling answering, the
   other picking up) are allowed, as the spec's LAN rule needs.
5. **A dodged bomb comes to rest.** A bomb stopped by a wall mid-air drops straight down to the first
   block below it (never below the arena floor), so it lies at the foot of the wall.
6. **The taunt** goes to the kid it missed only, in their chat, styled as his other lines.
7. **Safety floor mechanics.** Each hit on a kid in an arena run, on Peaceful or Easy, is capped at
   `health − 1` (half a heart left, the same floor as `wrongAnswerDamage`); a kid at half a heart
   takes nothing. Damage that bypasses invulnerability (`/kill`, the void) is not capped: the void is
   already caught by the world, and the parent's `/kill` must keep working. GameTests can't change
   the server's difficulty (global state), so `TafelBoemWorld.useDifficulty` lets them choose it.
8. **Dying is noticed on the world tick** (a kid of a run who `isDeadOrDying()`), not by a death
   event, so GameTests see it too. A kid who dies while answering loses the question (the bomb
   fizzles), or the rooting would pull the respawned kid back into the arena.

## Global Constraints

- `core/` imports nothing from `net.minecraft`, `com.mojang` or `net.fabricmc`
  (`CoreArchitectureTest`). Core code uses no `@Nullable`; it returns plain `null` where the Javadoc says so.
- Every user-facing string goes in both `en_us.json` and `nl_nl.json` with the same arguments
  (`LanguageFilesTest`). In English Graaf Fout is "Count Wrong". His taunt for a dodged bomb is
  *"Mis! Die ligt daar nog, hoor…"*; in a cactus or berry bush he says *"Au au au!"*.
- **Hit:** the bomb lands within **2 blocks** (horizontally) of the kid it was thrown at, measured
  where that kid stands when it lands. **Dodged:** further away; no line-of-sight check. No cap on
  lying bombs. He never throws at a kid who is answering.
- **Trap pull:** the nearest trap within **4 blocks** (horizontally), at most one per yeet, only on
  a yeet (traps only come after a correct answer). **+1 hit**; the trap block goes. Trap blocks:
  cactus, sweet berry bush, magma block, cobweb, slime block, a lying bomb. Honey is not a trap.
- **The chest:** 54 slots. Adds cactus, sand, sweet berries, dirt, magma blocks and cobweb, 16 each;
  wool goes to red, yellow and light blue. Never in it: TNT, lava, water, flint and steel, fire
  charges, dispensers, beds, spawn eggs.
- **Safety:** on Peaceful and Easy no damage takes a kid in an arena (build phase and fight) below
  half a heart; Normal and Hard are vanilla and dying counts as leaving (`died`). Whatever the
  difficulty: our booms never hurt (`PlayerSafeExplosion`); a typed wrong answer never takes the last
  half heart.
- **Switches** in `TafelBoemConfig`, default `true`: `dodging` (off = 1.2.0: wherever the bomb lands,
  its kid is rooted), `traps` (off = no pull, no bonus, the trap blocks stay in the chest),
  `arenaSafety` (off = vanilla damage everywhere, on every difficulty).
- **Logs:** the fight line gets per kid `dodged`, `pickedUp`, `trapped` (by kind); old lines without
  them still read. The yeet line gets `trap=<kind>`. `died` is a result next to `left`. Answers per
  minute keep counting from his arrival.
- Vanilla look: vanilla blocks and particles, his lines in the existing light-purple `<Count Wrong>`
  style; no new colours.
- Code style: tabs, Javadoc on every class, comments only where the why isn't obvious, match the
  surrounding code. When unsure of a Minecraft signature:
  `javap -cp .gradle/loom-cache/minecraftMaven/net/minecraft/minecraft-common-*/26.2/*.jar <class>`.
- GameTests: a test that runs 3 s or more gets `@Fight`; run a new slow test three times
  (`./gradlew runFightGameTests -Ptests=<id> -Prepeat=3`). Never change global state (difficulty,
  game rules, static hooks).
- Commits: subject = what changes for the kids or the parent, imperative; body = why; end with a
  `Co-Authored-By:` trailer naming the model that wrote the commit. Stage only the paths you changed.
  The kids are "Kid A" and "Kid B", the user is "the parent"; no home paths or IPs in committed files.
- Don't push, tag or publish. Playtest 4 judges the build phase first; R1.3 waits on its branch
  until the parent says otherwise.

```java
package nl.jeeninga.tafelboem.core;

/**
 * R1.3's dodge rule: a bomb Graaf Fout threw hits its kid only when it lands within 2 blocks of
 * where that kid stands then, horizontally; further away it lies still until a kid touches it. Cover
 * and running away are one rule: there is no line-of-sight check.
 */
public final class Dodging {
	/** From the middle of the block the bomb lands in to the kid's feet, horizontally. */
	public static final double HIT_RADIUS = 2;

	private Dodging() {
	}

	public static boolean isHit(double bombX, double bombZ, double kidX, double kidZ) {
		double dx = bombX - kidX;
		double dz = bombZ - kidZ;
		return dx * dx + dz * dz <= HIT_RADIUS * HIT_RADIUS;
	}

	/**
	 * A kid touches a lying bomb when their feet are in its block or a neighbouring one (diagonals
	 * too), at its height or standing on it.
	 *
	 * @param x the bomb block, as Minecraft counts blocks (its corner)
	 */
	public static boolean touches(int x, int y, int z, double kidX, double kidY, double kidZ) {
		return Math.abs(kidX - (x + 0.5)) < 1.5 && Math.abs(kidZ - (z + 0.5)) < 1.5 && kidY > y - 1 && kidY < y + 2;
	}
}
```

`src/main/java/nl/jeeninga/tafelboem/core/SafetyFloor.java`:

```java
package nl.jeeninga.tafelboem.core;

/**
 * Half a heart that nothing takes: on Peaceful and Easy in an arena (R1.3, switch
 * {@code arenaSafety}), and always for a typed wrong answer. On Normal and Hard an arena is vanilla.
 */
public final class SafetyFloor {
	/** Half a heart, in Minecraft's health points. */
	public static final float HALF_HEART = 1F;
	/** Minecraft's difficulty ids: 0 peaceful, 1 easy, 2 normal, 3 hard. */
	public static final int EASY = 1;

	private SafetyFloor() {
	}

	public static boolean protects(boolean arenaSafety, int difficultyId) {
		return arenaSafety && difficultyId <= EASY;
	}

	/** How much of a hit may land: all of it while it leaves half a heart; never more, and nothing at half a heart. */
	public static float allowed(float health, float damage) {
		return Math.max(0F, Math.min(damage, health - HALF_HEART));
	}
}
```

```java
package nl.jeeninga.tafelboem.core;

import java.util.Locale;

/**
 * The blocks a yeet after a right answer may pull Graaf Fout into (R1.3), and what he does in each.
 * Honey is no trap.
 */
public enum TrapKind {
	CACTUS(LandingStyle.PRICKLED, true),
	BERRY_BUSH(LandingStyle.PRICKLED, false),
	MAGMA(LandingStyle.FRANTIC_RUN, true),
	COBWEB(LandingStyle.WEBBED, false),
	SLIME(LandingStyle.BOING, true),
	/** A bomb from a dodge: it goes off under him, our usual safe boom. */
	LYING_BOMB(LandingStyle.SOOT, true);

	private final LandingStyle reaction;
	private final boolean landsOnTop;

	TrapKind(LandingStyle reaction, boolean landsOnTop) {
		this.reaction = reaction;
		this.landsOnTop = landsOnTop;
	}

	public LandingStyle reaction() {
		return reaction;
	}

	/** A solid block he lands on; otherwise (a bush, a cobweb) he lands in it. */
	public boolean landsOnTop() {
		return landsOnTop;
	}

	/** Cactus and berries prick: he says "Au au au!". */
	public boolean isPrickly() {
		return reaction == LandingStyle.PRICKLED;
	}

	/** For the logs. */
	public String id() {
		return name().toLowerCase(Locale.ROOT);
	}
}
```

```java
package nl.jeeninga.tafelboem.core;

import java.util.List;

/**
 * Which trap pulls Graaf Fout in at the end of one yeet: the nearest within 4 blocks (horizontally)
 * of where he would land, and at most one per yeet. One instance per yeet.
 */
public final class TrapPick {
	/** Horizontally, from where he would land to the middle of the trap block. */
	public static final double REACH = 4;

	/** A trap block, as Minecraft counts blocks (its corner), and what it is. */
	public record Candidate(int x, int y, int z, TrapKind kind) {
		double distanceSqr(double fromX, double fromZ) {
			double dx = x + 0.5 - fromX;
			double dz = z + 0.5 - fromZ;
			return dx * dx + dz * dz;
		}
	}

	private boolean picked;

	/** The nearest candidate in reach the first time there is one; null otherwise, and ever after. */
	public Candidate pick(double x, double z, List<Candidate> candidates) {
		if (picked) {
			return null;
		}
		Candidate nearest = nearest(x, z, candidates);
		picked = nearest != null;
		return nearest;
	}

	/** The nearest candidate within {@link #REACH}, the first of equals; null when none is in reach. */
	public static Candidate nearest(double x, double z, List<Candidate> candidates) {
		Candidate best = null;
		double bestSqr = REACH * REACH;
		for (Candidate candidate : candidates) {
			double distanceSqr = candidate.distanceSqr(x, z);
			if (best == null ? distanceSqr <= bestSqr : distanceSqr < bestSqr) {
				best = candidate;
				bestSqr = distanceSqr;
			}
		}
		return best;
	}
}
```

```java
import nl.jeeninga.tafelboem.core.LandingStyle;
import nl.jeeninga.tafelboem.core.YeetPose;

/** Landed in a cactus or a berry bush: he hops about on the spot, arms up, squeaking at every hop. */
final class PricklyLanding extends Landing {
	private static final int HOP_EVERY = 7;
	/** Small hops, so he stays by the trap and away from the kids. */
	private static final double HOP_SIDEWAYS = 0.06;

	PricklyLanding(GraafFout boss, Scene scene) {
		super(LandingStyle.PRICKLED, boss, scene);
	}

	@Override
	protected void begin(ServerLevel level) {
		boss.setYeetPose(YeetPose.NONE);
		boss.armsUp(true);
	}

	@Override
	protected void act(ServerLevel level) {
		if (ticks() % HOP_EVERY == 1 && boss.onGround()) {
			double angle = boss.getRandom().nextDouble() * Math.PI * 2;
			boss.setDeltaMovement(Math.cos(angle) * HOP_SIDEWAYS, 0.38, Math.sin(angle) * HOP_SIDEWAYS);
			boss.spin(90F);
			level.playSound(null, boss.getX(), boss.getY(), boss.getZ(), SoundEvents.EVOKER_HURT, SoundSource.HOSTILE, 1.0F, 1.8F);
			level.sendParticles(ParticleTypes.CRIT, boss.getX(), boss.getY() + 0.4, boss.getZ(), 6, 0.3, 0.2, 0.3, 0.05);
		}
	}
}
```

```java
	/** Trap blocks with room above them, around this spot, in this fight's arena. */
	private List<TrapPick.Candidate> trapsAround(Vec3 at) {
		List<TrapPick.Candidate> found = new ArrayList<>();
		BlockPos centre = BlockPos.containing(at);
		int reach = (int) Math.ceil(TrapPick.REACH);
		for (BlockPos pos : BlockPos.betweenClosed(centre.offset(-reach, -3, -reach), centre.offset(reach, 1, reach))) {
			if (arena != null && !arena.containsColumn(pos.getX() + 0.5, pos.getZ() + 0.5)) {
				continue;
			}
			TrapKind kind = trapAt(pos);
			// Only the top of a stack: he has to fit on or in it.
			if (kind != null && level.getBlockState(pos.above()).getCollisionShape(level, pos.above()).isEmpty()) {
				found.add(new TrapPick.Candidate(pos.getX(), pos.getY(), pos.getZ(), kind));
			}
		}
		return found;
	}

	private @Nullable TrapKind trapAt(BlockPos pos) {
		BlockState state = level.getBlockState(pos);
		if (state.is(Blocks.CACTUS)) {
			return TrapKind.CACTUS;
		}
		if (state.is(Blocks.SWEET_BERRY_BUSH)) {
			return TrapKind.BERRY_BUSH;
		}
		if (state.is(Blocks.MAGMA_BLOCK)) {
			return TrapKind.MAGMA;
		}
		if (state.is(Blocks.COBWEB)) {
			return TrapKind.COBWEB;
		}
		if (state.is(Blocks.SLIME_BLOCK)) {
			return TrapKind.SLIME;
		}
		// A bomb someone is answering is no trap; only a lying one is.
		return state.getBlock() instanceof BombBlock && lying.containsKey(pos) ? TrapKind.LYING_BOMB : null;
```
