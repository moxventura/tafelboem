# R1.1 "Meer yeets" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every hit on Graaf Fout becomes a flight plus a landing (wall splat, head-first, pancake,
frantic running, a signature per bomb), fast answers and streaks yeet him further with a personal
best per kid, and a Kippenbom counts its chickens out as the sum.

**Architecture:** The rules stay in the pure-Java `core` package with JUnit tests: the chicken count,
answer times, the boost, the streak, the reaction picker and its shuffle bag, the pacing, the
running circle, the pose transforms and the log lines. On the Minecraft side, landings get their own
classes in `boss/landing/` (like the yeets in `boss/yeet/`), the yeet-o-meter moves out of
`BossFight` into `YeetMeter`, `SessionManager` owns every spectacle animal's poof timer, and the
TafelBoem world hands each fight the kids' records from the fights log. Every feature has a switch.

**Tech Stack:** Java 25, Fabric Loader 0.19.5, Fabric API 0.161.0+26.2, Minecraft 26.2
(unobfuscated), JUnit 6 (with `junit-jupiter-params`), Fabric GameTests and client GameTests,
Python + Pillow for the soot texture.

**Spec:** `docs/superpowers/specs/2026-10-07-tafelboem-design.md`, section *R1.1 "Meer yeets"
(detailed scope)*. The approved high-level plan, with the developer, architect and tester review
findings, is the source of that section.

## Global Constraints

- The `core` package imports nothing from `net.minecraft`, `com.mojang` or `net.fabricmc`
  (`CoreArchitectureTest`). Core code doesn't use `@Nullable` annotations; it returns plain `null`
  where the docs say so.
- Every user-facing string exists in both `en_us.json` and `nl_nl.json` with the same arguments
  (`LanguageFilesTest`).
- The villain never states a wrong fact and never comments on the child's ability. A wrong answer is
  always shorter and less fun than a right one. No timers: a boost only ever adds.
- Only a typed wrong answer ends a streak; "?", ESC and a timeout don't.
- No ranking between siblings: the boost reason and the records show only to the kid who kicked.
- Every new feature has a switch in `TafelBoemConfig`, default `true`: `countingKippenbom`,

```java
package nl.jeeninga.tafelboem.core;

/**
 * The counting Kippenbom: for a × b, a chickens fly out and each pops into b, so the kids see the
 * sum as a groups of b. Two generations at most.
 *
 * @param groups   the first generation: a chickens, one per group
 * @param perGroup how many chickens each of them pops into
 */
public record ChickenCount(int groups, int perGroup) {
	/** A wrong answer: one chicken hops out, never more than the smallest right answer (1 × 1). */
	public static final int WRONG_ANSWER = 1;

	public static ChickenCount of(Fact fact) {
		return new ChickenCount(fact.a(), fact.b());
	}

	public int total() {
		return groups * perGroup;
	}

	/** How fast the first generation flies out: more groups fly further, so the groups stay apart. */
	public double ringSpeed() {
		return 0.2 + 0.03 * groups;
	}

	/** For the game log, for example "3x4: 3 groups of 4, 12 chickens (fight)". */
	public String describe(String where) {
		return groups + "x" + perGroup + ": " + groups + (groups == 1 ? " group of " : " groups of ") + perGroup + ", "
				+ total() + (total() == 1 ? " chicken" : " chickens") + " (" + where + ")";
	}
}
```

```java
	 * The reward: the bomb goes off where it stands. A Kippenbom's chickens come from the caller, who

	public static boolean boom(ServerLevel level, BlockPos pos, BombTier tier) {
		if (!(level.getBlockState(pos).getBlock() instanceof BombBlock)) {
			return false;
		}
		level.setBlock(pos, Blocks.AIR.defaultBlockState(), Block.UPDATE_ALL);
```

```java
	private static List<Chicken> releaseChickens(ServerLevel level, Vec3 center, int count, double speed, double lift) {
		List<Chicken> released = new ArrayList<>();
		for (int i = 0; i < count; i++) {
			Chicken chicken = EntityTypes.CHICKEN.create(level, EntitySpawnReason.TRIGGERED);
			if (chicken == null) {
				continue;
			}
			double angle = (Math.PI * 2 * i) / count;
			chicken.setPos(center.x, center.y + 0.5, center.z);
			chicken.setDeltaMovement(Math.cos(angle) * speed, lift + level.getRandom().nextDouble() * lift * 0.5, Math.sin(angle) * speed);
			chicken.addTag(SPECTACLE_TAG);
			level.addFreshEntity(chicken);
			released.add(chicken);
		}
		return released;
	}
```

```java
	/** The spectacle animals around this spot poof after a minute, like every bomb's. */
	public void collectSpectacles(ServerLevel level, BlockPos pos) {
		for (Entity entity : level.getEntities((Entity) null, new AABB(pos).inflate(3),
				entity -> entity.entityTags().contains(BombEffects.SPECTACLE_TAG))) {
			track(entity, SPECTACLE_LIFETIME_TICKS);
		}
	}

	/**
	 * This spectacle animal poofs after {@code ticks}. Animals that appear after the boom (the counting
	 * Kippenbom's groups, the chase) come here when they spawn: {@link #collectSpectacles} only finds
	 * what is there at the boom. Above {@link #MAX_SPECTACLES} the oldest go first.
	 */
	public void track(Entity entity, int ticks) {
		if (spectacles.stream().anyMatch(spectacle -> spectacle.entity == entity)) {
			return;
		}
		spectacles.add(new Spectacle(entity, ticks));
		while (spectacles.size() > MAX_SPECTACLES) {
			poof(spectacles.removeFirst().entity);
		}
	}

	/**
	 * The counting Kippenbom: one chicken per group flies out, and a second later each pops into its
	 * group, so the kids see a × b as a groups of b.

				continue;
			}

			for (Chicken first : burst.firsts) {
				BombEffects.popChicken(burst.level, first, burst.perGroup).forEach(chicken -> track(chicken, COUNTING_LIFETIME_TICKS));
			}
		}
	}

	private void tickSpectacles() {

			Spectacle spectacle = it.next();
			if (!spectacle.entity.isAlive()) {
				it.remove();
			} else if (--spectacle.ticksLeft <= 0) {
				poof(spectacle.entity);
				it.remove();
			}
		}
	}

		if (entity.isAlive() && entity.level() instanceof ServerLevel level) {
			BombEffects.poof(level, entity.position());
```

```java
import java.util.stream.LongStream;

/** The middle of some answer times, shared by the stats and the yeet-o-meter. */
public final class Medians {
	private Medians() {
	}

	/** The median: the mean of the two middle values for an even count, and 0 for none. */
	public static long of(LongStream values) {
		long[] sorted = values.sorted().toArray();
		if (sorted.length == 0) {
			return 0;
		}
		int middle = sorted.length / 2;
		return sorted.length % 2 == 1 ? sorted[middle] : (sorted[middle - 1] + sorted[middle]) / 2;
	}
}
```

```java
package nl.jeeninga.tafelboem.core;

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;
import java.util.OptionalLong;

/**
 * How fast a kid usually answers each sum (3 × 7 and 7 × 3 together): the median of their last 5
 * right answers. An answer clearly faster than that is "fast" and yeets Graaf Fout further. Ask for
 * the usual time before recording an answer, so an answer never counts towards its own.
 */
public final class AnswerTimes {
	static final int RECENT = 5;
	static final int MIN_ANSWERS = 3;
	/** Fast means under 80% of the usual time: a little faster is just a normal answer. */
	static final double FAST_SHARE = 0.8;

	private final Map<Fact, Deque<Long>> recent = new HashMap<>();

	public void record(Fact fact, Outcome outcome, long millis) {
		if (outcome != Outcome.CORRECT) {
			return;
		}
		Deque<Long> times = recent.computeIfAbsent(fact.family(), family -> new ArrayDeque<>());
		times.addLast(millis);
		if (times.size() > RECENT) {
			times.removeFirst();
		}
	}

	/** The usual time for this sum, or empty with fewer than 3 right answers on it. */
	public OptionalLong usual(Fact fact) {
		Deque<Long> times = recent.get(fact.family());
		if (times == null || times.size() < MIN_ANSWERS) {
			return OptionalLong.empty();
		}
		return OptionalLong.of(Medians.of(times.stream().mapToLong(Long::longValue)));
	}

	public static boolean isFast(OptionalLong usual, long millis) {
		return usual.isPresent() && millis < usual.getAsLong() * FAST_SHARE;
	}
}
```

```java
	}
}
```

```java
 * Each child's question picker and usual answer times, rebuilt from their answer log so progress
 * survives restarts.

public final class Learners {
	private record Learner(QuestionPicker picker, AnswerTimes times) {
	}

	private final AnswerLog log;
	private final Map<UUID, Learner> learners = new HashMap<>();

	public Learners(AnswerLog log) {
		this.log = log;
	}

	public Fact nextQuestion(ServerPlayer player, FightLevel level) {
		return learner(player).picker().next(level);
	}

	public void record(ServerPlayer player, Fact fact, Outcome outcome, int answer, long millis, BombTier tier, String context,
			String via, int typedDigits, FightLevel level) {
		Learner learner = learner(player);
		learner.picker().record(fact, outcome, millis);
		learner.times().record(fact, outcome, millis);
		log.append(new AnswerRecord(System.currentTimeMillis(), player.getPlainTextName(), fact.a(), fact.b(), answer,
				outcome, millis, tier.tier(), context, via, typedDigits, TafelBoem.version(), level.number()));
	}

	/** This kid's usual time for this sum, from the answers so far; ask before recording a new one. */
	public OptionalLong usualMillis(ServerPlayer player, Fact fact) {
		return learner(player).times().usual(fact);
	}

	public AnswerLog log() {
		return log;
	}

	private Learner learner(ServerPlayer player) {
		return learners.computeIfAbsent(player.getUUID(), id -> {
			Learner learner = new Learner(new QuestionPicker(new Random()), new AnswerTimes());

				learner.times().record(record.fact(), record.outcome(), record.millis());
```

```java
/**

 * Fout, how he flew and landed, and whether it beat the kid's record. The action bar never reaches
 * the log, so this is how a playtest shows what the yeet-o-meter did.
```

```java
import org.jspecify.annotations.Nullable;

import net.minecraft.ChatFormatting;
import net.minecraft.network.chat.Component;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.sounds.SoundEvents;

import nl.jeeninga.tafelboem.TafelBoem;
import nl.jeeninga.tafelboem.boss.yeet.Yeet;
import nl.jeeninga.tafelboem.config.TafelBoemConfig;
import nl.jeeninga.tafelboem.core.YeetReport;
import nl.jeeninga.tafelboem.game.QuizClient;

/**
 * The yeet-o-meter: after every yeet everyone in the fight sees how far Graaf Fout flew. The kid who
 * kicked also sees why he flew further (a fast answer, right answers in a row) and when it beat
 * their own record: personal bests only, never a ranking between siblings. Every kick also gets a
 * line in the game log, because the action bar never reaches it.
 */
final class YeetMeter {
	private final GraafFout boss;
	private final Participants participants;
	private final QuizClient client;
	private final TafelBoemConfig config;
	private @Nullable YeetRecords records;

	YeetMeter(GraafFout boss, Participants participants, QuizClient client, TafelBoemConfig config) {
		this.boss = boss;
		this.participants = participants;
		this.client = client;
		this.config = config;
	}

	void useRecords(@Nullable YeetRecords records) {
		this.records = records;
	}

	/**
	 * He is down after a yeet, or back after flying out of the arena.
	 *
	 * @param kick    the kick that sent him; null for a yeet on cue (a test)
	 * @param landing the landing's id, for the game log
	 * @param factor  how much further the kick sent him
	 */
	void landed(Yeet yeet, boolean flewOut, @Nullable Kick kick, String landing, boolean signature, double factor) {
		ServerLevel level = (ServerLevel) boss.level();
		ServerPlayer kicker = kick == null ? null : level.getServer().getPlayerList().getPlayer(kick.kicker());
		int blocks = yeet.blocks();
		int previousBest = 0;
		boolean record = false;
		if (kicker != null && records != null && !yeet.measuresHeight()) {
			previousBest = records.best(kicker);
			if (blocks > previousBest) {
				records.beaten(kicker, blocks);
				// The first yeet on file only sets the best: the first kick after the update is no record.
				record = previousBest > 0 && config.yeetRecords;
			}
		}

		if (flewOut || blocks >= 1) {
			String key = flewOut ? "tafelboem.message.yeet_out"
					: yeet.measuresHeight() ? "tafelboem.message.yeet_height" : "tafelboem.message.yeet_distance";
			Component plain = Component.translatable(key, boss.getDisplayName(), blocks).withStyle(ChatFormatting.AQUA, ChatFormatting.BOLD);
			for (ServerPlayer player : flewOut ? participants.players() : participants.nearBoss()) {
				client.actionBar(player, player == kicker ? forKicker(plain, kick, record, blocks) : plain);
			}
		}
		if (record) {
			client.sound(kicker, SoundEvents.UI_TOAST_CHALLENGE_COMPLETE);
		}
		if (kick != null) {
			String name = kicker != null ? kicker.getPlainTextName() : kick.kicker().toString();
			TafelBoem.LOGGER.info("TafelBoem yeet: {}", new YeetReport(name, kick.tier(), kick.fact(), kick.millis(), kick.usual(),
					kick.fast(), kick.streak(), factor, yeet.style(), landing, signature, blocks, yeet.measuresHeight(), flewOut,
					record, previousBest).describe());
		}
	}

	/** The kicker's own meter: a new record, or why he flew further. */
	private Component forKicker(Component plain, Kick kick, boolean record, int blocks) {
		if (record) {
			return Component.translatable("tafelboem.message.yeet_record", boss.getDisplayName(), blocks)
					.withStyle(ChatFormatting.GOLD, ChatFormatting.BOLD);
		}
		Component why = why(kick);
		return why == null ? plain : plain.copy().append(" ").append(why);
	}

	private @Nullable Component why(Kick kick) {
		if (!config.yeetBoost) {
			return null;
		}
		boolean streak = kick.streak() >= 2;
		if (kick.fast() && streak) {
			return Component.translatable("tafelboem.message.yeet_why.both", kick.streak());
		}
		if (kick.fast()) {
			return Component.translatable("tafelboem.message.yeet_why.fast");
		}
		return streak ? Component.translatable("tafelboem.message.yeet_why.streak", kick.streak()) : null;
	}
}
```

```java
package nl.jeeninga.tafelboem.core;

import java.util.List;
import java.util.Locale;

/**
 * What Graaf Fout does once a yeet has put him back on the ground. None lasts more than 2 s, and
 * {@link Pacing} takes the extra time off the pause before his next throw.
 */
public enum LandingStyle {
	/** Stars circle his head: the R1 landing, and the end of the boomerang and the wall splat. */
	DIZZY(30),
	/** Stuck head-first in the ground with his legs wiggling, then he pops out. */
	HEAD_FIRST(40),
	/** Squashed flat, waddles, then boing back into shape. */
	PANCAKE(40),
	/** Runs a small circle with smoke coming off his pants, arms waving. */
	FRANTIC_RUN(40),
	/** The Knalletje's signature: hops on one leg holding his toe, with confetti around his head. */
	TOE_HOP(40),
	/** The Gewone TNT's signature: a soot face with white eyes, coughing smoke. */
	SOOT(40),
	/** The Kippenbom's signature: angry chickens chase him round. */
	CHASED(40);

	/** The landings after any bomb; the others are signatures. */
	public static final List<LandingStyle> GENERIC = List.of(DIZZY, HEAD_FIRST, PANCAKE, FRANTIC_RUN);

	private final int ticks;

	LandingStyle(int ticks) {
		this.ticks = ticks;
	}

	public int ticks() {
		return ticks;
	}

	public boolean isSignature() {
		return !GENERIC.contains(this);
	}

	/** Running from chickens looks like running round in a panic, so the two count as one for "never twice in a row". */
	public boolean looksLike(LandingStyle other) {
		return this == other || other != null && isRunning() && other.isRunning();
	}

	private boolean isRunning() {
		return this == FRANTIC_RUN || this == CHASED;
	}

	/** For the game log. */
	public String id() {
		return name().toLowerCase(Locale.ROOT);
	}

	public static LandingStyle signatureOf(BombTier bomb) {
		return switch (bomb) {
			case KNALLETJE -> TOE_HOP;
			case GEWONE_TNT -> SOOT;
			case KIPPENBOM -> CHASED;
		};
	}
}
```

```java
package nl.jeeninga.tafelboem.core;

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Collections;
import java.util.Deque;
import java.util.Iterator;
import java.util.List;
import java.util.Random;
import java.util.function.Predicate;

/**
 * Hands out items in shuffled rounds: every item comes up once before any comes up again. The caller
 * says which items are allowed right now (not the one just shown, say); a new round starts when
 * none of the allowed ones is left in this one.
 */
public final class ShuffleBag<T> {
	private final List<T> items;
	private final Random random;
	private final Deque<T> round = new ArrayDeque<>();

	public ShuffleBag(List<T> items, Random random) {
		this.items = List.copyOf(items);
		this.random = random;
	}

	public T next(Predicate<T> allowed) {
		T next = take(allowed);
		if (next == null) {
			List<T> shuffled = new ArrayList<>(items);
			Collections.shuffle(shuffled, random);
			round.clear();
			round.addAll(shuffled);
			next = take(allowed);
		}
		if (next == null) {
			throw new IllegalArgumentException("None of " + items + " is allowed");
		}
		return next;
	}

	/** The first allowed item left in this round, taken out of it; null when there is none. */
	private T take(Predicate<T> allowed) {
		for (Iterator<T> it = round.iterator(); it.hasNext(); ) {
			T item = it.next();
			if (allowed.test(item)) {
				it.remove();
				return item;
			}
		}
		return null;
	}
}
```

```java
package nl.jeeninga.tafelboem.core;

import java.util.List;
import java.util.Random;

/**
 * Picks how Graaf Fout flies off after a kick and how he lands. Flights and landings come from
 * shuffled bags and never repeat back to back. A bomb's signature landing plays whenever the last
 * landing wasn't that signature, so it comes every other kick of that bomb.
 */
public final class ReactionPicker {
	private final ShuffleBag<YeetStyle> flights;
	private final ShuffleBag<LandingStyle> landings;
	private YeetStyle lastFlight;
	private LandingStyle lastLanding;

	public ReactionPicker(Random random) {
		this.flights = new ShuffleBag<>(List.of(YeetStyle.values()), random);
		this.landings = new ShuffleBag<>(LandingStyle.GENERIC, random);
	}

	/** How he flies off: every flight once before any comes again, never the same twice in a row. */
	public YeetStyle nextFlight() {
		YeetStyle last = lastFlight;
		lastFlight = flights.next(style -> style != last);
		return lastFlight;
	}

	/**
	 * How he lands after {@code flight}, which a kick with {@code bomb} sent him on.
	 *
	 * @param catalogue  false: no head-first, pancake or running, only the dizzy spell
	 * @param signatures false: no bomb signatures
	 */
	public LandingStyle nextLanding(BombTier bomb, YeetStyle flight, boolean catalogue, boolean signatures) {
		LandingStyle signature = LandingStyle.signatureOf(bomb);
		LandingStyle landing;
		if (flight.hasOwnEnding()) {
			landing = LandingStyle.DIZZY;
		} else if (signatures && !signature.looksLike(lastLanding)) {
			landing = signature;
		} else if (catalogue) {
			LandingStyle last = lastLanding;
			landing = landings.next(style -> !style.looksLike(last));
		} else {
			landing = LandingStyle.DIZZY;
		}
		played(landing);
		return landing;
	}

	/** A landing that played without being picked here: forced in a test, or the dizzy spell after flying out. */
	public void played(LandingStyle landing) {
		lastLanding = landing;
	}
}
```

```java
/**
 * What Graaf Fout does once a yeet has put him back on the ground, from {@link #start} until it has
 * run for its {@link LandingStyle#ticks()}. Each style is its own class, like the yeets, so a new
 * landing doesn't grow Graaf Fout.
 */
public abstract class Landing {
	/**
	 * Where a landing happens: the arena (null outside one), where the kids stand now, and how a
	 * spectacle animal gets its poof timer ({@code SessionManager::track}).
	 */
	public record Scene(@Nullable ArenaBox arena, Supplier<List<Vec3>> kids, BiConsumer<Entity, Integer> spectacle) {
		/** For a landing without a fight: no arena, no kids, nothing to poof. */
		public static final Scene NONE = new Scene(null, List::of, (entity, ticks) -> {
		});
	}

	protected final GraafFout boss;
	protected final Scene scene;
	private final LandingStyle style;
	private int ticks;

	protected Landing(LandingStyle style, GraafFout boss, Scene scene) {
		this.style = style;
		this.boss = boss;
		this.scene = scene;
	}

	public static Landing start(LandingStyle style, GraafFout boss, Scene scene, ServerLevel level) {
		Landing landing = switch (style) {
			case DIZZY -> new DizzyLanding(boss, scene);
			default -> throw new IllegalArgumentException("No landing built for " + style + " yet");
		};
		landing.begin(level);
		return landing;
	}

	public LandingStyle style() {
		return style;
	}

	/**
	 * One tick of the landing.
	 *
	 * @return true once it has run its course
	 */
	public final boolean tick(ServerLevel level) {
		ticks++;
		act(level);
		return ticks >= style.ticks();
	}

	/** Back on his feet: upright, arms down, hovering again. Also when a landing is cut short. */
	public void finish() {
		boss.setYeetPose(YeetPose.NONE);
		boss.armsUp(false);
		boss.setNoGravity(true);
	}

	protected void begin(ServerLevel level) {
	}

	protected abstract void act(ServerLevel level);

	/** Ticks since the landing began, this one included. */
	protected int ticks() {
		return ticks;
	}
}
```

```java
package nl.jeeninga.tafelboem.core;

/**
 * How Graaf Fout's body is turned, squashed or sunk on top of his usual spin, for the yeets and
 * landings that need more than a spin: the tumble, the boomerang's faceplant, head-first in the
 * ground and the pancake. Only the numbers live here; the renderer applies them.
 */
public enum YeetPose {
	NONE,
	TUMBLE,
	FACEPLANT,
	HEAD_FIRST,
	PANCAKE;

	/** Roll and flip at different speeds, so he tumbles instead of turning like a wheel. */
	public static final float TUMBLE_ROLL_PER_TICK = 35F;
	public static final float TUMBLE_PITCH_PER_TICK = 22F;
	/** How long tipping over onto his face takes. */
	public static final int FACEPLANT_TICKS = 5;
	/** How long getting back upright (and back into shape) takes after a pose ends. */
	public static final int SETTLE_TICKS = 6;
	/** How far his head goes into the ground, in blocks. */
	public static final float HEAD_FIRST_SINK = 0.6F;
	/** A pancake is a quarter of his height. */
	public static final float PANCAKE_HEIGHT = 0.25F;

	/**
	 * Roll (sideways) and pitch (negative is forward, onto his face) in degrees, height and depth as
	 * scale factors, and how far he is sunk into the ground in blocks.
	 */
	public record Transform(float roll, float pitch, float height, float depth, float sink) {
		public static final Transform UPRIGHT = new Transform(0F, 0F, 1F, 1F, 0F);
	}

	/** The transform {@code ticks} after this pose started. */
	public Transform transform(float ticks) {
		return switch (this) {
			case NONE -> Transform.UPRIGHT;
			case TUMBLE -> new Transform(halfTurn(ticks * TUMBLE_ROLL_PER_TICK), halfTurn(ticks * TUMBLE_PITCH_PER_TICK), 1F, 1F, 0F);
			case FACEPLANT -> faceplant(Math.min(1F, ticks / FACEPLANT_TICKS));
			case HEAD_FIRST -> new Transform(0F, 0F, 1F, 1F, HEAD_FIRST_SINK);
			case PANCAKE -> new Transform(0F, 0F, PANCAKE_HEIGHT, 1F, 0F);
		};
	}

	/** Where he turns round, as a share of his height: his middle for the tumble, his feet otherwise. */
	public float pivotShare() {
		return this == TUMBLE ? 0.5F : 0F;
	}

	/** Head-first is drawn upside down, the vanilla way. */
	public boolean upsideDown() {
		return this == HEAD_FIRST;
	}

	/** The pose a synced id stands for; an unknown one (a newer mod on the host) shows as none. */
	public static YeetPose byId(int id) {
		YeetPose[] poses = values();
		return id >= 0 && id < poses.length ? poses[id] : NONE;
	}

	private static Transform faceplant(float tipped) {
		return tipped <= 0F ? Transform.UPRIGHT : new Transform(0F, -90F * tipped, 1F, 1F, 0F);
	}

	/**
	 * Back to upright and back into shape, {@code ticks} after a pose ended at {@code from}. The angles
	 * are always within half a turn, so he never spins all the way round to get up; a pancake springs
	 * back to his height, which is the boing.
	 */
	public static Transform settle(Transform from, float ticks) {
		float left = 1F - ticks / SETTLE_TICKS;
		if (left <= 0F) {
			return Transform.UPRIGHT;
		}
		return new Transform(from.roll() * left, from.pitch() * left, 1F + (from.height() - 1F) * left, 1F + (from.depth() - 1F) * left,
				from.sink() * left);
	}

	/** Wraps degrees into [-180, 180). */
	private static float halfTurn(float degrees) {
		float wrapped = degrees % 360F;
		if (wrapped >= 180F) {
			wrapped -= 360F;
		} else if (wrapped < -180F) {
			wrapped += 360F;
		}
		return wrapped;
	}
}
```

```java
package nl.jeeninga.tafelboem.core;

import java.util.List;
import java.util.function.Predicate;

/**
 * Graaf Fout's frantic run: a small circle, starting where he landed. Every step must be over
 * ground, inside the arena and at least 2 blocks from every kid; when the next one isn't, he turns
 * round, and when neither way is free he stands still for a tick.
 */
public final class RunCircle {
	public static final double RADIUS = 2.5;
	/** He runs at 0.3 blocks a tick, so a step round the circle is 0.3 / 2.5 radians. */
	public static final double STEP = 0.12;
	public static final double KID_DISTANCE = 2;

	public record Point(double x, double z) {
	}

	private final double centreX;
	private final double centreZ;
	private double angle;
	private double direction = 1;

	/** @param startAngle where on the circle he starts, in radians; the circle goes through (x, z) there */
	public RunCircle(double x, double z, double startAngle) {
		this.centreX = x - Math.cos(startAngle) * RADIUS;
		this.centreZ = z - Math.sin(startAngle) * RADIUS;
		this.angle = startAngle;
	}

	public double centreX() {
		return centreX;
	}

	public double centreZ() {
		return centreZ;
	}

	/**
	 * Where to run to next.
	 *
	 * @param arena  null outside an arena
	 * @param ground whether a spot has ground he can run on
	 * @return the next point, or null to stand still this tick
	 */
	public Point next(ArenaBox arena, List<Point> kids, Predicate<Point> ground) {
		for (int attempt = 0; attempt < 2; attempt++) {
			double next = angle + direction * STEP;
			Point point = new Point(centreX + Math.cos(next) * RADIUS, centreZ + Math.sin(next) * RADIUS);
			if (allowed(point, arena, kids, ground)) {
				angle = next;
				return point;
			}
			direction = -direction;
		}
		return null;
	}

	private static boolean allowed(Point point, ArenaBox arena, List<Point> kids, Predicate<Point> ground) {
		if (arena != null && !arena.containsColumn(point.x(), point.z())) {
			return false;
		}
		for (Point kid : kids) {
			if (Math.hypot(point.x() - kid.x(), point.z() - kid.z()) < KID_DISTANCE) {
				return false;
			}
		}
		return ground.test(point);
	}
}
```

```java
package nl.jeeninga.tafelboem.boss.landing;

import java.util.List;

import net.minecraft.core.particles.ParticleTypes;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.sounds.SoundEvents;
import net.minecraft.sounds.SoundSource;
import net.minecraft.util.Mth;
import net.minecraft.world.level.levelgen.Heightmap;
import net.minecraft.world.phys.Vec3;

import nl.jeeninga.tafelboem.boss.GraafFout;
import nl.jeeninga.tafelboem.core.LandingStyle;
import nl.jeeninga.tafelboem.core.RunCircle;

/**
 * Runs a small circle in a panic: smoke coming off his pants, arms waving. Over ground only, never
 * into a crater deeper than 2 blocks, never closer than 2 blocks to a kid, and he pushes nobody.
 */
class FranticRunLanding extends Landing {
	private static final double SPEED = 0.3;
	private static final double JUMP = 0.42;
	private RunCircle circle;

	FranticRunLanding(GraafFout boss, Scene scene) {
		this(LandingStyle.FRANTIC_RUN, boss, scene);
	}

	protected FranticRunLanding(LandingStyle style, GraafFout boss, Scene scene) {
		super(style, boss, scene);
	}

	@Override
	protected void begin(ServerLevel level) {
		circle = new RunCircle(boss.getX(), boss.getZ(), boss.getRandom().nextDouble() * Math.PI * 2);
		boss.armsUp(true);
	}

	@Override
	protected void act(ServerLevel level) {
		List<RunCircle.Point> kids = scene.kids().get().stream().map(kid -> new RunCircle.Point(kid.x, kid.z)).toList();
		RunCircle.Point to = circle.next(scene.arena(), kids, point -> hasGround(level, point));
		Vec3 motion = boss.getDeltaMovement();
		if (to == null) {
			boss.setDeltaMovement(0, motion.y, 0);
		} else {
			Vec3 step = new Vec3(to.x() - boss.getX(), 0, to.z() - boss.getZ());
			Vec3 run = step.lengthSqr() > 1.0E-4 ? step.normalize().scale(SPEED) : Vec3.ZERO;
			boss.setDeltaMovement(run.x, boss.horizontalCollision && boss.onGround() ? JUMP : motion.y, run.z);
			if (run.lengthSqr() > 0) {
				boss.face(run);
			}
		}
		level.sendParticles(ParticleTypes.LARGE_SMOKE, boss.getX(), boss.getY() + 0.7, boss.getZ(), 1, 0.15, 0.1, 0.15, 0.01);
		if (ticks() % 10 == 1) {
			level.playSound(null, boss.getX(), boss.getY(), boss.getZ(), SoundEvents.EVOKER_HURT, SoundSource.HOSTILE, 0.8F, 1.7F);
		}
	}

	/** Ground he can run on: not the void, and not more than 2 blocks up or down from where he is. */
	private boolean hasGround(ServerLevel level, RunCircle.Point point) {
		int ground = level.getHeight(Heightmap.Types.MOTION_BLOCKING, Mth.floor(point.x()), Mth.floor(point.z()));
```

```java
import nl.jeeninga.tafelboem.core.YeetPose;
import nl.jeeninga.tafelboem.core.YeetStyle;

/**
 * Flies low and fast, slaps flat against the first wall he hits, sticks there for a moment and
 * slides down. With no wall in the way he just falls, like the classic yeet.
 */
final class WallSplatYeet extends Yeet {
	private static final int STUCK_TICKS = 12;
	private static final double SLIDE = 0.12;
	/** Pressed against the wall while he sticks and slides, so he doesn't drift off it. */
	private static final double PRESS = 0.05;
	/** Ticks since he hit the wall; -1 while he is still flying. */
	private int stuck = -1;

	WallSplatYeet(GraafFout boss, Vec3 away, double power) {
		super(YeetStyle.WALL_SPLAT, boss, away, power);
	}

	@Override
	protected void launch() {
		fling(power * 0.9, 0.3, false);
	}

	@Override
	protected boolean fly(ServerLevel level) {
		if (stuck < 0) {
			if (boss.horizontalCollision) {
				splat(level);
				return false;
			}
			boss.spin(30F);
			return boss.onGround() && ticks() > 5;
		}
		stuck++;
		if (stuck <= STUCK_TICKS) {
			boss.setDeltaMovement(away.scale(PRESS));
			return false;
		}
		boss.setDeltaMovement(away.x * PRESS, -SLIDE, away.z * PRESS);
		return boss.onGround();
	}

	private void splat(ServerLevel level) {
		stuck = 0;
		boss.setNoGravity(true);
		boss.face(away);
		boss.setYeetPose(YeetPose.SPLAT);
		level.playSound(null, boss.getX(), boss.getY(), boss.getZ(), SoundEvents.SLIME_SQUISH, SoundSource.HOSTILE, 2.0F, 0.6F);
		level.sendParticles(ParticleTypes.CLOUD, boss.getX() + away.x * 0.5, boss.getY() + 1, boss.getZ() + away.z * 0.5, 12, 0.2, 0.6, 0.2, 0.02);
	}
}
```

```python
# The Gewone TNT's signature: his whole head black with soot, only the whites of his eyes showing.

def soot():
    src = Image.open(ENTITY_OUT / "graaf_fout.png").convert("RGBA")
    out = src.copy()
    x0, y0, x1, y1 = HEAD
    for x in range(x0, x1):

    put(out, EYE_WHITES, WHITE)
    out.save(ENTITY_OUT / "graaf_fout_soot.png")
```
