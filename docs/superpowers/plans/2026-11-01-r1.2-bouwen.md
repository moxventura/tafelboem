# R1.2 "Bouwen" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A kid who walks through a level door first gets a build phase in the plain arena (a double
chest with a building kit, a bell, a countdown in the boss bar), and Graaf Fout appears when the time
runs out or someone rings the bell; the fight itself is 1.1.2's.

**Architecture:** The rules are pure Java in `core/` with JUnit tests: the build time per level
(`BuildPhase`), the countdown with its chat calls and the bell rule (`BuildCountdown`), the chest's
contents (`BuildKit`) and the log line (`BuildRecord`). On the Minecraft side, `ArenaRun` gets a
countdown instead of a fixed start tick, a new `Building` holds one arena's boss bar, bell ringer and
placed-block counts, and `BuildCorner` places the chest and bell. `TafelBoemWorld` gets the
`BuildPhase` through its constructor, so GameTests choose their own (off by default) and nothing
reads the static config for it.

**Tech Stack:** Java 25, Fabric Loader 0.19.5, Fabric API 0.161.0+26.2 (incl. `UseBlockCallback`),
Minecraft 26.2 (unobfuscated), JUnit 6, Fabric GameTests and client GameTests.

**Spec:** `docs/superpowers/specs/2026-10-07-tafelboem-design.md`, section *R1.2 "Bouwen" (detailed
scope)*. Read it first; this plan argues from it.

## Global Constraints

- `core/` imports nothing from `net.minecraft`, `com.mojang` or `net.fabricmc`
  (`CoreArchitectureTest`). Core code uses no `@Nullable`; it returns plain `null` where the Javadoc says so.
- Every user-facing string goes in both `en_us.json` and `nl_nl.json` with the same arguments
  (`LanguageFilesTest`). In English Graaf Fout is "Count Wrong" (as in the existing lines).
- Build times: **300 s on Makkelijk, 240 s on Gemiddeld, 180 s on Moeilijk.**
- The bell: remaining = `min(remaining, 10 s)`, never longer. Chat calls at **10, 5, 3, 2, 1** seconds left,
  also when the time runs out on its own.
- Build-phase chat and boss bar reach only the kids in that arena's run (`kidsIn(run)`), never the whole LAN.
- The chest is a double chest (54 slots). Never in it: TNT, lava, water, flint and steel, cactus,
  sweet berries, magma, dispensers, beds, spawn eggs.
- Switch `buildPhase` in `TafelBoemConfig`, default `true`. Off = 1.1.2: random arenas from
  `ArenaCatalog.place`, no chest or bell, he comes 60 ticks after the first kid.
- The fight's `seconds` in the fights log count from his arrival; the build time goes in a new
  `buildSeconds` field. Old lines without it read as 0.
- Vanilla look: vanilla blocks, vanilla boss bar (purple, like his), chat in gold like the door
  messages; no new colours.
- Code style: tabs, Javadoc on every class, comments only where the why isn't obvious, match the
  surrounding code. When unsure of a Minecraft signature:
  `javap -cp .gradle/loom-cache/minecraftMaven/net/minecraft/minecraft-common-*/26.2/*.jar <class>`.
- GameTests: a test that runs 3 s or more gets `@Fight`; run a new slow test three times
  (`./gradlew runFightGameTests -Ptests=<id> -Prepeat=3`). Never change global state.
- Commits: subject = what changes for the kids or the parent, imperative; body = why; end with a
  `Co-Authored-By:` trailer naming the model that wrote the commit. Stage only the paths you changed.
- Don't push, tag or publish. The release is the parent's call, after the plan is done.

```java
package nl.jeeninga.tafelboem.core;

/**
 * Whether the kids build the arena before Graaf Fout comes (R1.2), and for how long per level: the
 * easier the level, the longer they build.
 */
public record BuildPhase(boolean on, int makkelijkSeconds, int gemiddeldSeconds, int moeilijkSeconds) {
	public static final BuildPhase STANDARD = new BuildPhase(true, 300, 240, 180);
	/** 1.1.2: no build phase, he comes 3 s after the first kid. */
	public static final BuildPhase OFF = new BuildPhase(false, 0, 0, 0);

	/** The same time on every level: for tests, which can't wait minutes. */
	public static BuildPhase everyLevel(int seconds) {
		return new BuildPhase(true, seconds, seconds, seconds);
	}

	public int seconds(FightLevel level) {
		return switch (level) {
			case MAKKELIJK -> makkelijkSeconds;
			case GEMIDDELD -> gemiddeldSeconds;
			case MOEILIJK -> moeilijkSeconds;
			default -> throw new IllegalArgumentException("No arena, so no build phase, for " + level);
		};
	}
}
```

`src/main/java/nl/jeeninga/tafelboem/core/BuildCountdown.java`:

```java
package nl.jeeninga.tafelboem.core;

import java.util.Locale;

/**
 * The time until Graaf Fout comes, in ticks: what the boss bar shows, which seconds the arena's chat
 * calls out (10, 5, 3, 2, 1) and the bell, which brings him within 10 s but never later. A countdown
 * on building, never on answering a sum.
 */
public final class BuildCountdown {
	public static final int TICKS_PER_SECOND = 20;
	public static final int BELL_SECONDS = 10;
	private static final int[] CALLS = {10, 5, 3, 2, 1};

	private final int total;
	private int remaining;
	/** The first of {@link #CALLS} not called out yet. */
	private int nextCall;

	public BuildCountdown(int ticks) {
		this.total = ticks;
		this.remaining = ticks;
		skipCallsAtOrAbove(ticks);
	}

	/** One tick on. Returns the second to call out in chat now, or 0. */
	public int tick() {
		if (remaining > 0) {
			remaining--;
		}
		int call = 0;
		while (nextCall < CALLS.length && remaining <= CALLS[nextCall] * TICKS_PER_SECOND) {
			call = CALLS[nextCall++];
		}
		return call;
	}

	/**
	 * The bell: at most {@link #BELL_SECONDS} left, never more than before. True when it brought him
	 * closer; the bell's own chat line then says the seconds, so the calls go on below them.
	 */
	public boolean ring() {
		int bell = BELL_SECONDS * TICKS_PER_SECOND;
		if (remaining <= bell) {
			return false;
		}
		remaining = bell;
		skipCallsAtOrAbove(remaining);
		return true;
	}

	public boolean isOver() {
		return remaining == 0;
	}

	public int ticksLeft() {
		return remaining;
	}

	/** Rounded up, so the clock never shows 0:00 while he hasn't come yet. */
	public int secondsLeft() {
		return (remaining + TICKS_PER_SECOND - 1) / TICKS_PER_SECOND;
	}

	/** As the boss bar shows it: "4:59". */
	public String clock() {
		int seconds = secondsLeft();
		return seconds / 60 + ":" + String.format(Locale.ROOT, "%02d", seconds % 60);
	}

	/** How full the boss bar is: 1 at the start, 0 when he comes. */
	public float progress() {
		return total == 0 ? 0F : (float) remaining / total;
	}

	private void skipCallsAtOrAbove(int ticks) {
		while (nextCall < CALLS.length && CALLS[nextCall] * TICKS_PER_SECOND >= ticks) {
			nextCall++;
		}
	}
}
```

```java
package nl.jeeninga.tafelboem.core;

import java.util.Comparator;
import java.util.Map;
import java.util.stream.Collectors;

/**
 * One arena's build phase, as a {@code TafelBoem build:} line in the game log for the evaluation:
 * how long they built, how it ended, and what each kid placed from the kit.
 *
 * @param seconds from the first kid's entry until he came, or until the last kid left
 * @param ending  {@link #BELL}, {@link #TIME} or {@link #EVERYONE_LEFT}
 * @param rangBy  the kid who rang the bell first; null unless the bell ended it
 * @param kids    how many kids were in the run
 * @param placed  per kid, in the order they came: item id → how many placed
 */
public record BuildRecord(int level, long seconds, String ending, String rangBy, int kids, Map<String, Map<String, Integer>> placed) {
	public static final String BELL = "bell";
	public static final String TIME = "time";
	public static final String EVERYONE_LEFT = "everyone left";

	public String describe() {
		String how = switch (ending) {
			case BELL -> "the bell (" + rangBy + ")";
			case TIME -> "time ran out";
			default -> ending;
		};
		String byKid = placed.entrySet().stream().map(kid -> kid.getKey() + " " + placedBy(kid.getValue())).collect(Collectors.joining(", "));
		return "level " + level + ", built " + seconds + " s, " + how + ", " + kids + (kids == 1 ? " kid" : " kids") + "; placed: " + byKid;
	}

	private static String placedBy(Map<String, Integer> items) {
		int total = items.values().stream().mapToInt(Integer::intValue).sum();
		if (total == 0) {
			return "nothing";
		}
		return total + " (" + items.entrySet().stream()
				.filter(item -> item.getValue() > 0)
				.sorted(Map.Entry.<String, Integer>comparingByValue().reversed().thenComparing(Map.Entry.comparingByKey(Comparator.naturalOrder())))
				.map(item -> item.getKey() + " " + item.getValue())
				.collect(Collectors.joining(", ")) + ")";
	}
}
```

```java
	/** Clears the level's slot and places one of its arenas, picked at random, never twice in a row. */
	public PlacedArea place(ServerLevel level, WorldLayout layout, FightLevel fightLevel, Consumer<String> skipped) {
		ArenaBox slot = layout.arenaSlot(fightLevel);
		// Check them all before picking: a pick that is then skipped would break "never twice in a row".
		Map<String, StructureTemplate> usable = new LinkedHashMap<>();
		for (Identifier id : templatesFor(fightLevel)) {
			Optional<StructureTemplate> template = templates.get(id);
			if (template.isPresent() && hasExitDoor(template.get())) {
				usable.put(id.toString(), template.get());
			} else {
				skipped.accept(id.toString());
			}
		}

		clearLast(level, slot, fightLevel);
		PlacedArea arena;
		if (!usable.isEmpty()) {
			ArenaPicker picker = pickers.computeIfAbsent(fightLevel, key -> new ArenaPicker(random));
			String name = picker.pick(List.copyOf(usable.keySet()));
			StructureTemplate found = usable.get(name);
			arena = ShapePlacer.placeTemplate(level, WorldLayout.cornerFor(slot, found.getSize().getX(), found.getSize().getZ()), name, found);
		} else {
			arena = placeShape(level, slot, fightLevel);
		}
		lastPlaced.put(fightLevel, Optional.of(arena.bounds()));
		setMusic(level, slot, arena, fightLevel);
		return arena;
	}

	/**
	 * The build phase's arena: always the plain one from code, templates or not. The kids build on it,
	 * up to the top of the slot and beside the walls, so the next entry clears all of the slot.
	 */
	public PlacedArea placePlain(ServerLevel level, WorldLayout layout, FightLevel fightLevel) {
		ArenaBox slot = layout.arenaSlot(fightLevel);
		clearLast(level, slot, fightLevel);
		PlacedArea arena = placeShape(level, slot, fightLevel);
		lastPlaced.put(fightLevel, Optional.of(slot));
		setMusic(level, slot, arena, fightLevel);
		return arena;
	}

	/** Blocks only where the last arena stood (all of the slot when that isn't known); stray entities anywhere in it. */
	private void clearLast(ServerLevel level, ArenaBox slot, FightLevel fightLevel) {
		lastPlaced.getOrDefault(fightLevel, Optional.of(slot)).ifPresent(box -> ShapePlacer.clearBlocks(level, box));
		// After the blocks: a chest that went to air spilled its kit, and that goes too.
		ShapePlacer.clearEntities(level, slot);
	}

	private static PlacedArea placeShape(ServerLevel level, ArenaBox slot, FightLevel fightLevel) {
		Shape shape = ArenaShape.forLevel(fightLevel.number());
		return ShapePlacer.placeShape(level, WorldLayout.cornerFor(slot, shape.sizeX(), shape.sizeZ()), shape);
	}

	/** Over the arena, from the bottom to the top of its slot: wherever a kid is in it, the music plays. */

		ArenaBox over = arena.bounds();
		ArenaBiomes.set(level, new ArenaBox(over.minX(), slot.minY(), over.minZ(), over.maxX(), slot.maxY(), over.maxZ()), fightLevel,
```

```java
import java.util.List;

import net.minecraft.core.BlockPos;
import net.minecraft.core.Direction;
import net.minecraft.core.registries.BuiltInRegistries;
import net.minecraft.resources.Identifier;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.world.Container;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.level.block.BellBlock;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.Blocks;
import net.minecraft.world.level.block.ChestBlock;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.level.block.state.properties.BellAttachType;
import net.minecraft.world.level.block.state.properties.ChestType;

import nl.jeeninga.tafelboem.core.BuildKit;

/**
 * The build phase's corner of an arena: a double chest with the {@link BuildKit} and a bell, a few
 * blocks ahead of where the kids arrive, so they see both first and the exit door is behind them.
 */
public final class BuildCorner {
	/** Blocks from the arrival spot, in the way the kids look. */
	static final int AHEAD = 3;

	private BuildCorner() {
	}

	/** The chest's first half (the one {@link #place} fills from), three blocks ahead of the arrival spot. */
	public static BlockPos chestAt(PlacedArea arena) {
		return arena.standAt().relative(ahead(arena), AHEAD);
	}

	public static BlockPos bellAt(PlacedArea arena) {
		return chestAt(arena).relative(front(arena).getCounterClockWise(), 2);
	}

	/** Places the chest, fills it, and places the bell; whatever stood there goes. */
	static void place(ServerLevel level, PlacedArea arena) {
		Direction front = front(arena);
		BlockPos left = chestAt(arena);
		// A chest's LEFT half finds its RIGHT half clockwise of where it faces (ChestBlock.getConnectedDirection).
		BlockPos right = left.relative(front.getClockWise());
		BlockState chest = Blocks.CHEST.defaultBlockState().setValue(ChestBlock.FACING, front);
		level.setBlock(left, chest.setValue(ChestBlock.TYPE, ChestType.LEFT), Block.UPDATE_CLIENTS);
		level.setBlock(right, chest.setValue(ChestBlock.TYPE, ChestType.RIGHT), Block.UPDATE_CLIENTS);
		Container container = ChestBlock.getContainer((ChestBlock) Blocks.CHEST, level.getBlockState(left), level, left, true);
		if (container == null || container.getContainerSize() < BuildKit.SLOTS) {
			throw new IllegalStateException("No double chest at " + left);
		}
		List<BuildKit.Stack> kit = BuildKit.CHEST;
		for (int slot = 0; slot < kit.size(); slot++) {
			container.setItem(slot, stack(kit.get(slot)));
		}

		// A floor bell rings when hit on a side along its facing axis: the side the kids see from the arrival spot.
		level.setBlock(bellAt(arena), Blocks.BELL.defaultBlockState()
				.setValue(BellBlock.FACING, front)
				.setValue(BellBlock.ATTACHMENT, BellAttachType.FLOOR), Block.UPDATE_CLIENTS);
	}

	static ItemStack stack(BuildKit.Stack stack) {
		return new ItemStack(BuiltInRegistries.ITEM.getOptional(Identifier.withDefaultNamespace(stack.item()))
				.orElseThrow(() -> new IllegalStateException("No item " + stack.item() + " in this Minecraft")), stack.count());
	}

	/** The way the kids look when they arrive. */
	private static Direction ahead(PlacedArea arena) {
		return Direction.fromYRot(arena.yaw());
	}

	/** The way the chest's lid and the bell face: back at the kids. */
	private static Direction front(PlacedArea arena) {
		return ahead(arena).getOpposite();
	}
}
```

```java
package nl.jeeninga.tafelboem.world;

import java.util.HashMap;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;
import java.util.UUID;

import org.jspecify.annotations.Nullable;

import net.minecraft.core.registries.BuiltInRegistries;
import net.minecraft.network.chat.Component;
import net.minecraft.resources.Identifier;
import net.minecraft.server.level.ServerBossEvent;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.stats.Stats;
import net.minecraft.world.BossEvent;

import nl.jeeninga.tafelboem.core.BuildCountdown;
import nl.jeeninga.tafelboem.core.BuildKit;

/**
 * One arena's build phase: the boss bar with the countdown (where his health shows in the fight),
 * who rang the bell, and what each kid placed from the kit. Placing is counted with Minecraft's own
 * "used" statistic, from when a kid came in until they left or he came.
 */
public final class Building {
	private final ServerBossEvent bar = new ServerBossEvent(UUID.randomUUID(), Component.empty(), BossEvent.BossBarColor.PURPLE,
			BossEvent.BossBarOverlay.PROGRESS);
	private final Map<UUID, Map<String, Integer>> usedAtJoin = new HashMap<>();
	private final Map<String, Map<String, Integer>> placed = new LinkedHashMap<>();
	private @Nullable String rangBy;
	private String shownClock = "";
	private boolean finished;

	void joined(ServerPlayer kid) {
		usedAtJoin.putIfAbsent(kid.getUUID(), used(kid));
		placed.computeIfAbsent(kid.getPlainTextName(), name -> new TreeMap<>());
	}

	/** Adds what the kid placed since they came in; a kid who comes back is counted again from then. */
	void left(ServerPlayer kid) {
		Map<String, Integer> before = usedAtJoin.remove(kid.getUUID());
		if (before == null) {
			return;
		}
		Map<String, Integer> kidPlaced = placed.computeIfAbsent(kid.getPlainTextName(), name -> new TreeMap<>());
		used(kid).forEach((item, now) -> {
			int more = now - before.getOrDefault(item, 0);
			if (more > 0) {
				kidPlaced.merge(item, more, Integer::sum);
			}
		});
	}

	/** Everything placed, per kid in the order they came; counts the kids still building up to now. */
	Map<String, Map<String, Integer>> placed(List<ServerPlayer> stillIn) {
		stillIn.forEach(this::left);
		return new LinkedHashMap<>(placed);
	}

	/** The countdown in the boss bar of exactly these kids. */
	void show(List<ServerPlayer> kids, BuildCountdown countdown) {
		String clock = countdown.clock();
		if (!clock.equals(shownClock)) {
			shownClock = clock;
			bar.setName(Component.translatable("tafelboem.build.countdown", clock));
			bar.setProgress(countdown.progress());
		}
		for (ServerPlayer shown : List.copyOf(bar.getPlayers())) {
			if (!kids.contains(shown)) {
				bar.removePlayer(shown);
			}
		}
		for (ServerPlayer kid : kids) {
			if (!bar.getPlayers().contains(kid)) {
				bar.addPlayer(kid);
			}
		}
	}

	void hide() {
		bar.removeAllPlayers();
	}

	public boolean isShownTo(ServerPlayer kid) {
		return bar.getPlayers().contains(kid);
	}

	public Component title() {
		return bar.getName();
	}

	public @Nullable String rangBy() {
		return rangBy;
	}

	/** Only the first kid who rang counts: the bell can't bring him any sooner after that. */
	void rungBy(String kid) {
		if (rangBy == null) {
			rangBy = kid;
		}
```
